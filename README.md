# Credit Risk EDA

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on credit application data to understand customer financial behavior and identify factors associated with loan repayment difficulties.

## 🎯 Objectives

* Analyze customer demographics and financial information.
* Identify patterns related to credit risk.
* Understand the relationship between income, credit amount, age, employment, and repayment difficulty.
* Analyze previous loan application patterns.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 🔍 Key Analysis

* Data cleaning and missing-value analysis
* Univariate and bivariate analysis
* Outlier detection
* Feature engineering
* Age and employment analysis
* Credit amount categorization
* Target variable analysis
* Previous application analysis
* Data visualization

## 📊 Key Insights

The analysis identified patterns in customer income, age, employment, loan amount, and previous application status that can help understand factors associated with credit repayment risk.

## 📂 Dataset

The project uses application and previous-application financial datasets containing customer demographic, income, credit, loan, and repayment-related information.

## 🚀 How to Run

1. Clone this repository.
2. Open the `.ipynb` file in Jupyter Notebook or Google Colab.
3. Install the required Python libraries.
4. Run the notebook cells sequentially.
